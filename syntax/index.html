어순과 문장 구조

한국어와 포르투갈어는 어순이 정반대인 지점과 의외로 같은 지점이 함께 있다. 같은 곳부터 확인하면 부담이 줄어든다.

한국어와 같은 것

  • ✓주어 생략이 된다
  • ✓의문문에서 어순을 바꾸지 않는다
  • ✓맥락으로 많은 것을 생략한다

다른 것

  • ·동사가 문장 가운데 온다
  • ·꾸미는 말이 명사 뒤에 온다
  • ·전치사가 명사 앞에 온다
  • ·설명하는 절이 명사 뒤에 붙는다
  • ·명사에 성별이 있다
  • ·관사가 있다
  • ·높임을 인칭으로 처리한다
  • ·접속법이라는 별도의 동사 형태가 있다

같은 세 가지 덕분에 영어보다 시작이 편하다. 다른 여덟 가지 중에서는 '동사 위치'와 '꾸미는 말 위치' 두 개만 먼저 몸에 붙이면 대화가 굴러간다. 나머지는 순서대로 온다.

다름1단계

동사가 가운데로 온다

한국어
주어 — 목적어 — 동사 (나는 커피를 마신다)
포르투갈어
주어 — 동사 — 목적어 (Eu bebo café)
  • 나는 커피를 마신다.
    나 / 마신다 / 커피
  • 그녀는 뒷마당에서 삼바를 부른다.
    그녀 / 부른다 / 삼바 / ~에서 / 뒷마당

한국어는 동사를 끝까지 들어야 뜻이 완성된다. 포르투갈어는 두 번째 낱말에서 이미 무엇을 하는지 나온다. 듣는 순서 자체가 다르다.

듣기 훈련에서 '동사를 먼저 잡는다'는 감각으로 바꾸면 훨씬 편해진다. 끝까지 기다릴 필요가 없다.

다름1단계

꾸미는 말이 뒤에 온다

한국어
흰 집 — 꾸미는 말이 앞
포르투갈어
casa branca — 꾸미는 말이 뒤
  • 흰 집 하나
    하나의 / 집 / 흰
  • 오래된 브라질 음악
    그 / 음악 / 브라질의 / 오래된

한국어 화자는 형용사를 명사 앞에 놓으려 한다. branca casa 라고 말하는 실수가 초기에 반복된다.

명사를 먼저 던지고 설명을 붙인다고 생각한다. '집 — 흰 — 오래된' 순서다.

다름1단계

조사 대신 앞에 붙는 전치사

한국어
뒷마당'에서' — 명사 뒤에 붙는다
포르투갈어
no quintal — 명사 앞에 온다
  • 파티는 뒷마당에서 한다.
    그 / 파티 / 이다 / ~에서 / 뒷마당
  • 나는 브라질로 간다.
    나 / 간다 / ~로 / 그 / 브라질

한국어는 조사를 붙일 때까지 명사를 말하고 나서 결정할 수 있다. 포르투갈어는 관계를 먼저 정해야 명사를 말할 수 있다.

전치사와 관사가 자주 합쳐진다. em + o = no, de + a = da. 이 축약형을 통째로 외우는 편이 빠르다.

한국어와 같음1단계

주어를 생략할 수 있다 — 한국어와 같다

한국어
(나는) 커피 마셔
포르투갈어
Bebo café — eu 없이도 된다
  • 포르투갈어 해요.
    (나) 말한다 / 포르투갈어
  • 못 알아들었어요.
    안 / (나) 이해했다

어렵지 않다. 오히려 영어를 배울 때보다 편한 지점이다.

동사 어미가 주어를 알려 주기 때문에 생략이 가능하다. 한국어와 이유는 다르지만 결과는 비슷하다. 브라질 구어에서는 você와 eu를 붙이는 경우도 많다.

한국어와 같음1단계

의문문 어순이 그대로다 — 한국어와 같다

한국어
너 여기 살아? — 어순 그대로 끝만 올린다
포르투갈어
Você mora aqui? — 어순 그대로 억양만 올린다
  • 삼바 좋아해?
    너 / 좋아한다 / ~를 / 삼바
  • 어디 살아?
    어디 / 너 / 산다

영어처럼 do/does를 넣거나 어순을 뒤집지 않는다. 한국어 화자에게는 자연스러운 구조다.

의문사만 문장 앞으로 나온다. 나머지는 평서문과 같다.

다름1단계

부정은 동사 앞에 하나만

한국어
안 먹어 / 먹지 않아 — 두 가지 자리
포르투갈어
Não como — 언제나 동사 앞
  • 나는 스페인어를 안 해.
    나 / 안 / 말한다 / 스페인어
  • 그는 아무 말도 안 했어.
    그 / 안 / 말했다 / 아무것도

이중 부정이 정상이라는 점이 낯설다. não과 nada가 함께 나와도 부정이 강해질 뿐 상쇄되지 않는다.

não을 동사 바로 앞에 놓는 것만 지키면 된다. 나머지는 따라온다.

다름2단계

설명하는 절이 뒤에 붙는다

한국어
내가 어제 산 책 — 설명이 명사 앞에 통째로 온다
포르투갈어
o livro que eu comprei ontem — 설명이 명사 뒤에 온다
  • 내가 어제 산 책
    그 / 책 / ~인데 / 나 / 샀다 / 어제
  • 모두가 부르는 노래
    그 / 노래 / ~인데 / 온 / 세상 / 부른다

한국어는 설명이 길어지면 명사가 한참 뒤에 나온다. 포르투갈어는 명사를 먼저 던지고 설명을 붙인다. 문장을 만드는 머릿속 순서를 바꿔야 한다.

que 하나로 대부분 해결된다. 사람이든 사물이든 que를 쓰고 뒤에 문장을 이어 붙인다.

다름1단계

모든 명사에 성별이 있다

한국어
없음
포르투갈어
o quintal (남성) / a casa (여성) — 관사와 형용사가 따라 바뀐다
  • 큰 뒷마당
    그(남) / 뒷마당 / 큰
  • 흰 집
    그(여) / 집 / 흰
  • 흰 집들
    그들(여) / 집들 / 흰들

한국어에 대응이 전혀 없어서 감이 잡히지 않는다. 게다가 형용사와 관사까지 함께 바뀐다.

명사를 외울 때 관사를 붙여서 통째로 외운다. quintal이 아니라 o quintal로.

다름1단계

관사가 있다

한국어
없음. '그 집'과 '집'을 문맥으로 구분한다
포르투갈어
o / a / os / as 와 um / uma 가 거의 항상 붙는다
  • 나는 (그) 삼바를 좋아한다.
    나 / 좋아한다 / ~의+그 / 삼바
  • 책 한 권 샀어.
    (나) 샀다 / 하나의 / 책

언제 붙이고 언제 빼는지가 규칙만으로 정리되지 않는다. 나라 이름, 사람 이름, 신체 부위에서 관습이 갈린다.

초반에는 '거의 항상 붙인다'로 두고 예외를 만날 때마다 표시해 둔다. 빼먹는 것보다 붙이는 쪽이 덜 어색하다.

다름2단계

목적격 대명사의 자리

한국어
나를 도와줘 — 조사가 붙어 자리가 자유롭다
포르투갈어
Me ajuda / Ajuda-me — 위치가 정해져 있고 지역마다 다르다
  • 나 좀 도와줄 수 있어?
    너 / 할 수 있다 / 나를 / 돕다
  • 나중에 전화할게.
    나 / 너에게 / 전화한다 / 나중에

브라질에서는 동사 앞에 두는 것이 자연스럽고 포르투갈에서는 뒤에 붙여 쓰는 경우가 많다. 교재와 실제 회화가 어긋나 보인다.

브라질 구어를 목표로 한다면 동사 앞에 두는 형태만 익혀도 충분하다.

다름1단계

'이다'가 둘, '있다'가 셋

한국어
이다 / 있다 두 개로 다 된다
포르투갈어
ser · estar / ter · haver · ficar 로 나뉜다
  • 나는 한국인이다.
    나 / 이다(본질) / 한국인
  • 나는 피곤하다.
    나 / 이다(상태) / 피곤한
  • 커피 있어요?
    (그것이) 가진다 / 커피
  • 그 집은 광장에 있다.
    그 / 집 / 위치한다 / ~에 / 광장

한국어에서 하나로 처리하던 것이 여러 갈래로 나뉜다. 특히 '있다'가 소유·존재·위치로 갈린다.

존재를 말할 때 브라질 구어는 거의 항상 ter를 쓴다. haver는 문어에서 만난다.

다름3단계

형용사 위치가 뜻을 바꾸기도 한다

한국어
없음
포르투갈어
um homem grande (덩치 큰 남자) / um grande homem (훌륭한 남자)
  • 덩치가 큰 남자
    한 / 남자 / 큰
  • 위대한 남자
    한 / 위대한 / 남자

위치가 자유로운 것이 아니라 위치에 따라 뜻이 달라지는 낱말이 따로 있다. velho, pobre, novo 등이 그렇다.

기본은 뒤에 두는 것이다. 앞에 오면 대개 주관적·비유적 의미가 된다.

다름2단계

높임이 어휘가 아니라 인칭으로 간다

한국어
동사 어미와 어휘로 높인다 (하십니다 / 진지)
포르투갈어
você / o senhor 처럼 부르는 말을 바꾼다
  • 커피 드시겠어요?
    그 / 선생님 / 원한다 / 하나의 / 커피
  • 커피 마실래?
    너 / 원한다 / 하나의 / 커피

한국어처럼 촘촘한 등급이 없다. 반대로 한국어 화자는 지나치게 격식을 차리다가 거리감을 만들기도 한다.

브라질에서는 você가 기본이다. 나이 많은 사람이나 공적인 자리에서만 o senhor / a senhora를 쓴다. 포르투갈은 기준이 더 엄격하다.

다름3단계

접속법 — 한국어에 없는 문법

한국어
없음. 어미나 부사로 처리한다
포르투갈어
확실하지 않은 것, 바람, 감정 뒤에 동사 형태가 따로 있다
  • 네가 오면 좋겠어.
    (나) 바란다 / ~것을 / 너 / 오다(접속법)
  • 아마 그는 집에 있을 거야.
    아마 / 그 / 있다(접속법) / ~에 / 집

한국어에 대응 개념이 없어서 '왜 형태가 바뀌는지'가 감으로 안 잡힌다. B1 이후의 최대 관문이다.

지금 외우지 않아도 된다. 다만 espero que, talvez, quero que 뒤에서 동사 모양이 달라진다는 것만 알아 두면 나중에 덜 놀란다.

다름3단계

강조하려고 어순을 뒤집는다

한국어
조사와 억양으로 강조한다
포르투갈어
말하고 싶은 것을 앞으로 뺀다
  • 모든 게 시작된 건 바로 뒷마당이었다.
    ~에서 / 뒷마당 / 이다 / ~것 / 모두 / 시작했다
  • 그건 나도 몰랐어.
    그것 / 나 / 안 / 알았다

기본 어순이 SVO라고 배운 뒤에 이런 문장을 만나면 규칙이 깨진 것처럼 보인다.

노래 가사와 국가(國歌)에 특히 많다. 문학적인 문장일수록 어순이 흔들린다고 보면 된다.

gloss는 포르투갈어 낱말을 한국어로 하나씩 옮긴 것이다. 문장이 아니라 구조를 보라고 넣었다.
