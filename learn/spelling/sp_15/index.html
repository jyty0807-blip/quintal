브라질 철자와 포르투갈 철자

1990년 정서법 협정으로 상당 부분 통일됐지만 아직 다른 것이 남아 있다.

협정의 목표는 두 표기를 하나로 맞추는 것이었다. 브라질은 2009년, 포르투갈은 2009년부터 단계적으로 시행했다.

바뀐 것

  • 트레마 폐지 — lingüiça → linguiça
  • 포르투갈 쪽에서 발음되지 않는 자음 삭제 — óptimo → ótimo, acção → ação
  • 일부 강세 부호 폐지 — idéia → ideia, vôo → voo

    • 아직 다른 것

  • 포르투갈에서는 실제로 발음되는 자음은 그대로 둔다. facto(포) / fato(브)
  • receção(포) / recepção(브)
  • 어휘 자체가 다른 경우가 훨씬 많다. trem(브) / comboio(포), ônibus(브) / autocarro(포)

    • 이 앱은 브라질 표기를 기준으로 한다. 포르투갈 자료를 볼 때 철자가 달라 보이면 대개 이 때문이다.

    소리로 확인

    함정

    2009년 이전에 나온 책과 웹 자료는 옛 철자를 쓴다. 검색할 때 둘 다 시도해 보는 편이 낫다.
