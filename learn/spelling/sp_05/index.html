C의 두 얼굴, 그리고 Ç

c + a/o/u = ㅋ, c + e/i = ㅅ. a·o·u 앞에서 ㅅ이 필요하면 ç를 쓴다.

c는 뒤에 오는 모음이 결정한다.

  • casa(카자), cor(코르), curso(쿠르수) — ㅋ
  • cinco(싱쿠), cedo(세두) — ㅅ

    • 그런데 a·o·u 앞에서 ㅅ 소리를 내고 싶으면 어떻게 하나. c 밑에 꼬리를 단다. 그것이 ç다.

    그래서 ç는 절대 e나 i 앞에 오지 않는다. 거기서는 그냥 c로 충분하기 때문이다.

    같은 단어의 활용에서 이 교체가 보인다. começar(코메사르) → comece(코메시). c 앞이 e로 바뀌자 꼬리가 사라졌다.

    소리로 확인

    함정

    ç를 e·i 앞에 쓰면 틀린 철자다. çe, çi는 존재하지 않는다.
